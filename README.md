# Telmi Sync - Synchronize your stories and music with Telmi OS

This application is for installing Telmi OS and synchronized stories and music with Telmi OS.

You can install Telmi Sync on Windows 10+ (x64), MacOS (x64, arm64), Linux (x64).

## Installation sur macOS

Telmi Sync n'est pas signée par un développeur identifié par Apple. Au premier lancement, macOS affiche le message « Élément « Telmi Sync.app » non ouvert ».

1. Cliquez sur **Terminé**.
2. Ouvrez **Réglages Système** > **Confidentialité et sécurité**.
3. Dans la section **Sécurité**, cliquez sur **Ouvrir quand même** à côté de « Telmi Sync.app ».
4. Dans la boîte de confirmation, cliquez de nouveau sur **Ouvrir quand même**.
